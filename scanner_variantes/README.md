# scanner_variantes

Carpeta reservada para variantes, legados, copias de trabajo y herramientas auxiliares de scanner.

Regla del proyecto:
- `SCANNER/` contiene solo scanners productivos promovidos y congelados.
- Los nombres productivos canonicos pueden ser:
  - `invertir_vN.py` para saltos mayores.
  - `invertir_vN_M.py` para mejoras menores promovidas sin cambio fuerte de familia.
- Cualquier variante no promovida, research ejecutable, copia de trabajo o legado descriptivo vive aca.

Ejemplos actuales:
- `invertir_v10_rebound_capture.py`
- `invertir_v13_1_hold_display.py`
- `invertir_v13_2_auto_hygiene.py`
- `invertir_v13_3_dynamic_special.py`
- `scanner_niveles.py`
